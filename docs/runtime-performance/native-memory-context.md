# Native memory recall context

The ordinary source-file-free recall path fuses eligibility/ranking, ordered
field projection, previous-body truncation and output budget decisions into one
existing native request. Python retains the final compatible JSON serialization
and the canonical non-authoritative warning header.

MemoryContext is pure and reuses MemoryRecall. It has no filesystem, process,
store, provider or write authority. String-only rendering follows Python JSON
spacing and Unicode scalar counts. Duplicate predecessor IDs use the last
record; output skips oversized records and keeps room for later short records.

The NativeMemoryContext adapter only admits ordinary scalar/string fields and
validates a closed projected packet. Source-backed records, custom projection
or JSON/calendar bindings, opaque metadata and unsupported budgets keep the
existing path. An attempted-but-declined fused request uses the pure recall
reference, preventing a second ranking process. Fully cached source-status
checks retain their existing in-process fast path, including empty cached blobs,
duplicate path order and changed-before-unavailable precedence.
